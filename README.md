## 📝 Project Overview

The **MY SCHOOL - Study Buddy Platform** is a fully-featured e-learning platform that connects **students**, **tutors**, and **admin users**. It allows tutors to upload study materials and create study sessions, while students can enroll in sessions, attend classes, and leave feedback. The admin manages user roles, session approvals, and system control.

This project fulfills all the requirements of **Assignment12_category_022**.

## 🎯 Key Features

### 👨‍🎓 Student Panel
- View available study sessions
- Book sessions (Free or Paid)
- Done payment using secure system
- Access tutor-uploaded study materials
- Leave feedback + ratings after session ends
- Private Dashboard with personal session management

### 👨‍🏫 Tutor Panel
- Create study sessions (with proper details)
- Upload study materials (PDF / Docs / Resources)
- View enrolled student list
- Manage personal teaching dashboard

### 👑 Admin Panel
- Approve / Reject study sessions
- Manage users (Promote to Tutor / Admin)
- View payment and session reports
- Maintain system quality
